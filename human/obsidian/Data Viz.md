# Data visualisation

Data is vector geometry. A decorative hatch is a separate clipped layer and is fixed in opacity, spacing and angle regardless of value.

| Component | Required rule |
| --- | --- |
| `Data/Economics-bar` | Values use 0–100 scale. Exact 8% and 70% fills. Coral hand-drawn finish, fine double contour, spaced diagonal hatch and endpoint construction mark. Wording: `~8p for every pound` and `Porto: up to 70p for every pound`. Include the independent-artist/all-declared-rights qualification. |
| `Data/Allocation-donut` | True circles and arcs, fixed inner radius. Exact 70/30 traditional and 70/25/5 Porto values. Cream rights-holder, violet operator, blue treasury, coral platform. No label pill or glass casing. |
| `Data/Proportional-bar` | Label, value, unit, source and empty state. 0% remains an outlined zero-length state, no fake fill. |
| `Data/Bar-line` | Numeric axis, baseline, source, units and accessible tabular alternative. |
| `Data/Timeline` and `Data/Milestone` | Date, title, status, qualification, source. Pending is not complete. |
| `Data/Venn` | Artist and Distributor have separate areas. Porto is centred in overlap. Areas must not imply quantitative value unless labelled. |
| `Data/Process-flow` | Direction arrows, step labels and a text alternative. Never make architectural art carry process semantics. |
| `Data/Table` | Header, numeric alignment, source and overflow variant. |

Allocation language: 70% is a rights-holder pool, not a guaranteed individual artist payout. The 25% operator share requires participating by operating eligible infrastructure. Accrual and settlement are separate. Beta's default settlement epoch is daily. Use these statements only with a linked source note.
