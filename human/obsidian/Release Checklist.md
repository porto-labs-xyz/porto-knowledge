# Release checklist

- [ ] Figma project is private and ownership is confirmed.
- [ ] Named Figma version maps to package version.
- [ ] All listed component masters exist and have descriptions.
- [ ] Instances remain linked after an edit to a master.
- [ ] A variable change propagates to expected instances only.
- [ ] Long headline, long label and table overflow are tested.
- [ ] Economics bars are exactly 8% and 70%; donuts are exactly 70/30 and 70/25/5.
- [ ] Hatching is visually constant across different values.
- [ ] `player-responsive.svg` remains 154:332.
- [ ] Exports have legible type, no clipped artwork and accessible alternatives.
- [ ] Deck, report and campaign representative examples are visually inspected.
- [ ] Release manifest has Figma URLs, file keys, node IDs, asset hashes and export evidence.
