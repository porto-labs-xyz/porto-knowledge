# Porto Design System package instructions

Use released package content only. Do not ingest restricted deck PDFs, private valuations, biographies or local source paths. Read the design-system skill before producing a Porto visual artifact. Keep Figma node IDs and links in `figma/release-manifest.json`; do not invent them.

Figma is the editable visual authority. The package is release evidence. Never state that a local export, plugin script or specification is a Figma implementation until the Figma file and inspected nodes are recorded.
